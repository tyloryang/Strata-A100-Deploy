## 二、三个共同前提

1. **GPU 是独占的。** 两张 A100-40G 已经被 IQ3_XXS 的 Strata 服务占满。部署这里任何一个模型，要么先停掉 IQ3_XXS 服务（会中断线上），要么换一台机器。不能两套同时跑。
2. **数字不能互相借用。** IQ3_XXS 的显存账本、内存账本、吞吐、TPOT 都不能直接套到这些模型上，必须各自实测。
3. **不要在离线机上跑 `setup.sh --calibrate`。** 它会在依赖检查失败时删掉 `.venv` 再联网重装，离线机装不回来（测试机 21:36 出过这个事故，见[部署文档 §12.8](../docs/部署文档.md#128-三次事故)）。`/data/strata-src.tar` 是唯一一份完整 venv 的副本，不能删。

## 三、可以共用的东西

- **镜像和引擎**：`strata-qwen38:cuda12-1.0` 和 `engine-cuda12/strata` 对 IQ3_S、Coder 同样适用（vLLM 除外）。
- **PLE 表分片**：所有 GSQ-RCO 量化档（IQ3_XXS / IQ3_S / Coder IQ1_M）的第 2 个分片是**同一个文件**（sha256 `316b46f3a2dbd68c900f43136ab9449f9dcc3725dfd8c794847c204bc161e113`），可以硬链接去重，测试机上这样做省了 27 GB。
- **部署流程、compose、脚本**：和 IQ3_XXS 相同，只换模型相关的路径和参数。参数含义见 [参数详解](../docs/参数详解.md)。
