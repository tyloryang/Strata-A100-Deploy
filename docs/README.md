## 三、必须先知道的四件事

### 1. 早期吞吐数字是地板值

早期 62 个用例都用 `--dataset random`。随机 token 让 MTP 接受率只有 2–5%，前缀缓存命中恒为 0%。后来的 B 轮改用了自然中文。详见压测文档 §1.3。

### 2. `parallel` 不是引擎参数

引擎没有 `--parallel`。真正的开关是 `--batch N`，由配置顶层的 `parallel` 经 `server.py` 翻译（上限 8）。推荐配置在 `args` 里也显式写了 `--batch`，**两处要一致**。验证：`/slots` 返回几条就是几个槽位。

### 3. 内存是这台机器的主要约束，显存不是

专家已经 100% 在显存，显存没占满是正常的。紧张的是 94 GiB 内存：PLE 表、每个槽位约 3.6 GB 的锁页 KV、会话缓存都在里面。曾因 `parallel=8` + 8 个 200K 并发把机器压到假死近 50 分钟。**200K 场景并发 ≤ 4。** 详见压测文档 §6。

### 4. 有几个参数"写了但不起作用"

`STRATA_ROUTE_TAIL_SKIP`（专家全在显存时无事可做）、`STRATA_ADAPT_OVERLAP*`（只在单卡生效）、`--batch-mtp`（层拆分 + 流水线时被引擎关掉）。前两个是整理时根据官方文档和源码确认的，详见[参数详解 §3](参数详解.md#3-引擎层env-环境变量)。

## 四、未验证项与已结案项

### 仍未验证（IQ3_XXS）

| 项 | 怎么验 |
|---|---|
| `--prefill auto:32768` 相对 `auto` 的收益（setup 注释称 +21~35%） | 单变量 A/B，看预填 tok/s 和 GPU0 余量 |
| 会话缓存在多轮负载下的真实价值 | 多轮第 12 轮 TTFT，开/关对比 |
| `--kv k8v4` 的收益与质量 | 与 int8 对比解码速度和锁页内存，抽查质量 |
| 去掉 `--kv-resident` 同时把 `--max-context` 降到 65536 | 日志仍 100% resident、两卡 VRAM free ≥ 1 GB、内存上升 |
| 不开 ESP 的原模型基线 | `experimental_speed_projection: false` 重跑 A/B 两轮 |
| `--conversation-cache-mib 0` 为何仍停放会话 | 查 0.1.45 源码或换 `--conversation-cache-slots 0` 试 |
| `--resident-experts` 对解码的影响 | 开/关对比（专家全在显存，预期无差异） |
| 升级引擎到 0.2.7+ 后的 `STRATA_PIPED_MTP`、两卡逐层读 prompt | 见[参数详解 §7](参数详解.md#7-升级引擎后才能用的本机-0145-没有属于-iq3_xxs-的待验证项) |
| 驱动 535 跑 CUDA 12.4 引擎 | 迁移到目标机时验证 |

### 已结案

| 项 | 结论 | 依据 |
|---|---|---|
| `--batch-mtp` 是否生效 | 默认流水线下被关掉；强制串行后生效但慢 16–20% | 压测文档 §9、§11 |
| 4 槽 vs 8 槽 | 长提示 4 槽最优；短提示高并发 8 槽聚合更高但 TPOT 翻倍 | 压测文档 §12 |
| `--ple-io ram` vs `mmap` | 性能无差异，`ram` 锁死 26.8 GiB 内存 | 压测文档 §12.4 |
| `--kv-resident` 能否去掉 | 不能（单独去掉时显存 99%、并发 8 崩 35%） | 部署文档 §12.6 |
| ESP 是否生效 | v4 起按请求生效；它是拒答方向投影，不是提速 | 官方 DETAILS.md、参数详解 §2.7 |
| `STRATA_ROUTE_TAIL_SKIP` 0 vs 7 | **本机等价，不需要测** | Strata 源码 + DETAILS.md |
| `STRATA_ADAPT_OVERLAP*` 是否在双卡生效 | **不生效** | 本机日志 `is off: not on a layer split` |
| `--expert-cache-device1` / `--expert-cache-per-layer` 能否扩专家缓存 | **不需要**，专家已 100% 在显存 | 本机日志 + Web 监控页 |
| `--pipeline-windows 2` | 有 batch 槽位时引擎自动关闭 | 官方 MULTI_GPU.md |
| 专家缓存是否只有一半 | **否**，早期误读 | 本机日志 `12288 of its 12288`、`100% of the experts resident` |

## 六、文档维护约定

1. **改配置后同步三处**：`deploy/` 下的配置文件、[参数详解](参数详解.md)的"本机值"、受影响的压测数字。
2. **数字必须带配置前提**。同一台机器在不同槽位、`ple-io`、预填块下的性能差异可以到 60%，跨批次比较前先核对当时的配置（部署文档 §12.2 有版本表）。
3. **"未验证"就写"未验证"**，"估算"就写"估算"。
4. **其他模型的内容只放 `待实施-其他模型/`**，不要和 IQ3_XXS 的结论混写。
5. **所有地址与凭证一律用占位符**：`<公网IP>`、`<SSH端口>`、`<内网IP>`、`<Key>`。真实 Key 只在 `/etc/strata/api_key` 和配置 JSON（均 600）。
