# Strata IQ3_XXS 运维卡片（单页）

> 适用：本机已部署完成的 `strata` 容器（`/data/qwen-strata`，端口 `<内网IP>:8080`）
> 完整过程见 `执行记录.md`，复现到新机器见 `plan-新内网机器复现.md`

## 一、日常操作（compose 管理，当前状态）

```bash
cd /data/compose/strata
docker-compose ps                       # 看 (healthy)
docker-compose logs -f                  # 等价 docker logs -f strata
docker-compose restart                  # 重启，77 秒恢复 healthy
docker-compose stop                     # 停止，13 秒，显存释放
docker-compose start                    # 启动，65 秒 healthy
docker-compose down                     # 删容器+网络，不碰 /data
docker-compose up -d                    # 起回来，65 秒 healthy
docker-compose config                   # 改完 YAML 先校验
```

compose 不可用时（内网机没预置二进制）用等价的 docker 命令：

```bash
docker ps | grep strata
docker logs -f strata
docker restart strata                   # 约 54–77 秒重新 ready
docker stop strata                      # 约 13–14 秒，显存回到 1MiB
docker start strata
bash /root/offline_check/start_strata.sh   # 从零重建（docker run 方式）
```

改了 `strata-iq3_xxs.json` 必须重启才生效。

> **警告：不要对运行中的 strata 执行 `docker rm -f` / `docker kill`。**
> 引擎占着 CUDA 上下文，被 SIGKILL 后要拆 GPU 上下文，进程进入不可中断状态，docker 等不到退出事件就报错，容器留在不一致状态、服务中断。实测两种写法都会失败（`is zombie` / `did not receive an exit event`），加 `init: true` 也不能解决。
> 要重建就 `docker-compose down` 再 `up -d`（各 13/65 秒，干净）。真卡死了等它自己变 `Exited (137)`（约 5 分钟）再删。

## 二、接口

| 用途 | 地址 |
| --- | --- |
| **Web 聊天页（公网）** | `http://<公网IP>:13270/`  或  `http://<公网IP-电信>:13270/` |
| **OpenAI / Anthropic（公网）** | `...:13270/v1/chat/completions`、`...:13270/v1/messages` |
| 健康检查（公网） | `...:13270/health` |
| 模型列表 | `...:13270/v1/models` |
| 槽位 / 状态 | `...:13270/slots`、`...:13270/v1/status` |
| 本机运维 | `http://127.0.0.1:8800/health`（VM 内 8800） |

`/v1` 只是 API 前缀，浏览器直接开 `/v1` 是 404，Web 页在 `/`。

端口链路（三层，缺一层就不通）：

```
公网 13270 → VM 8800 → 容器 8080
  平台转发      compose published     容器内监听(0.0.0.0:8080)
```

平台预留了 6 组：`13270→8800`、`13271→8801`、`13272→8802`、`13273→8803`、`13274→8804`、`13275→8805`。**发布端口只能落在这 6 个里面**，换端口就改 compose 的 `'${BIND_IP}:8800:8080'` 前半段，并同步告诉使用者新的公网端口。

容器内服务自己监听 `0.0.0.0:8080`（`strata-iq3_xxs.json` 的 `host`/`port`），这个不用动；只改 published 端口即可换公网入口。

模型名随便填（返回 `qwen3.8-flash-next-iq3_xxs`）。请求头必须带 `Authorization: Bearer <Key>`。

### 外部访问

公网入口由平台转发，已验证可用（2026-11-02 07:40 从外网直连实测 200）：

| 入口 | 地址 |
| --- | --- |
| 移动 | `http://<公网IP>:13270/` |
| 电信 | `http://<公网IP-电信>:13270/` |

如果这两个都打不开，按顺序查：

```bash
# 1) 容器是否健康、端口是否发布
docker-compose ps                       # 要 (healthy)
docker port strata                      # 要 8080/tcp -> 0.0.0.0:8800
# 2) VM 是否在监听
ss -ltnp | grep 8800
# 3) 平台转发是否还是 13270->8800（控制台截图为准）
# 4) 临时替代：SSH 隧道
ssh -N -L 18080:<内网IP>:8800 -p <SSH端口> root@<公网IP>
#    浏览器 http://127.0.0.1:18080/
```

**Key 位置**：`/etc/strata/api_key`（600）；配置里也在 `strata-iq3_xxs.json`（600）。不要贴到聊天/文档里。

```bash
KEY=$(cat /etc/strata/api_key)
curl -s http://127.0.0.1:8800/health
curl -s http://127.0.0.1:8800/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
  -d '{"model":"x","messages":[{"role":"user","content":"你好"}],"max_tokens":100,"reasoning_effort":"none"}'
```

注意：现在绑的是 `0.0.0.0`，所以 VM 内 `127.0.0.1` 和内网 IP 都通（端口是 8800）。如果哪天改回只绑 `<内网IP>`，宿主 `127.0.0.1:8800` 就会不通（容器内仍可用 `docker exec strata curl 127.0.0.1:8080/health`）。

## 三、当前配置要点

| 项 | 值 | 说明 |
| --- | --- | --- |
| `gpu` | `[0, 1]` | 双卡层拆分，`layer_split: auto` |
| `--max-context` | 262144 | 模型训练长度上限 |
| `--kv` | int8 | KV 精度 |
| `--kv-resident` | 32768 | KV 常驻显存的窗口，其余在内存 |
| `--ple-io` | ram | 29GB n-gram 表放内存（磁盘是虚拟盘，必须） |
| 专家缓存 | 12288 个 / 17.72 GiB 显存 | 越接近全部越好 |
| parallel | 1（默认） | 并发要开 `--parallel N`，每槽约 0.6GB 显存 |

## 四、改配置

```bash
B=/data/qwen-strata
cp $B/Strata/strata-iq3_xxs.json $B/Strata/strata-iq3_xxs.json.bak.$(date +%s)
# 方式一：重跑 setup（会重新生成，参数带上要改的项）
docker run --rm --gpus '"device=0,1"' -e KEY="$(cat /etc/strata/api_key)" \
  --security-opt label=disable --ulimit memlock=-1:-1 -v $B:/data \
  strata-qwen38:cuda12-1.0 bash -c 'cd /data/Strata && ./setup.sh --setup --no-start --yes \
  --cuda 12 --model IQ3_XXS --gpus 0,1 --vision no --context 262144 --parallel 4 \
  --no-browser --host 0.0.0.0 --api-key "$KEY" \
  --data-dir /data/Strata-data --models-dir /data/Strata-data/models'
docker restart strata
# 方式二：只改 JSON 里的字段（parallel / context / gpu / layer_split），改完同样 restart
```

## 六、常见故障

| 现象 | 处理 |
| --- | --- |
| `loaded: false` 很久 | `docker logs strata` 看是否还在加载；首次加载 70 秒，重启 54 秒 |
| 容器起不来报 CUDA 版本 | 加 `-e NVIDIA_DISABLE_REQUIRE=true` |
| Permission denied | 用 `--security-opt label=disable`（本机 SELinux 已 Disabled，一般不会遇到） |
| 显存不够 / 专家落内存 | 降 `--context`（262144→131072）、加 `--kv q4_0`、或降 `--parallel` |
| 端口被占 | `ss -ltnp \| grep 8080` |
| `docker rm -f` 报 zombie / did not receive an exit event | 容器卡在中间态：等它变 `Exited (137)`（约 5 分钟），或 `systemctl restart docker`；之后 `docker-compose up -d` |
| `docker-compose ps` 显示 unhealthy | `docker inspect -f '{{json .State.Health}}' strata` 看最近几次探测输出 |
| 内存吃紧 | `free -h`；`--ple-io ram` 占 29GB，必要时改 `--ple-io disk`（慢） |
